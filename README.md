# Higher Luck

**Group:** GROUP MEMBERS
**Course:** Object Oriented Programming, 2026 Fall (Project 1)
**Type:** Windows Forms application, C#, .NET Framework 4.8

Higher Luck is a two-player dice game. Each player has a name, an avatar and points. Players take turns rolling a dice for a number of rounds chosen at the start, and the player with more points at the end wins. Every finished game is saved to a text file and can be shown again at any time.

## How to run

1. Extract the zip file.
2. Open `GROUP_MEMBERS_Project1.sln` in Visual Studio (2019 or 2022).
3. Press **F5** (Start).

If Visual Studio asks for the .NET Framework 4.8 targeting pack, install it, or change the target framework under *Project > Properties > Application*.

## How to play

1. Choose the number of **Rounds** (minimum 5, maximum 30).
2. Write the **First Player Name** and the **Second Player Name**. The *Set Up* buttons become active only after both names are written.
3. Select an avatar and click **Set Up First Player**. Then select a different avatar and click **Set Up Second Player**. An avatar that is already taken is disabled, so both players can not have the same one. After the set up, the name is shown in capital letters and the button and the name box are disabled.
4. Click **START**. The black label shows whose turn it is.
5. The player on turn clicks **ROLL**. The dice picture shows the rolled number.
6. After both players have rolled, the round is scored:
   - the player with the bigger dice value gets one point;
   - if the values are equal, both players get one point.
7. The **Rounds left** counter goes down after each round. When it reaches 0, the winner is announced (or "No winner" if the points are equal) and the result is saved to the file. After clicking OK, the program resets for a new game.
8. **SHOW RESULT** can be clicked at any time. It shows all saved games in the Report list box.
9. **RESET ALL** can be clicked at any time. It resets everything to the beginning.

## Saved results

Results are stored only in a text file (there is no database). The file `GameResults.txt` is created next to the program (the `.exe`). When the program is started from Visual Studio, this is the `bin\Debug` folder.

Each game is one line:

```
NAME1;POINTS1;NAME2;POINTS2;RESULT
VLADYSLAV;3;DMYTRO;2;The winner is VLADYSLAV
```

## Project structure

| File | Purpose |
|------|---------|
| `Player.cs` | Class for one player: name, avatar, points, and whether the player is set up. |
| `Game.cs` | Class with the game rules: turns, dice roll, scoring, rounds left and the winner text. |
| `Form1.cs` | The only form: reacts to the buttons, shows the information, and does the file operations. |
| `Form1.Designer.cs` | Layout of the form (generated by the Visual Studio designer). |
| `Program.cs` | Entry point of the application. |
| `Properties/Resources.resx` | The avatar and dice pictures, stored inside the program. |
| `Resources/` | The original picture files (4 avatars, default avatar, 6 dice faces). |

## What the project uses

- **Classes:** `Player` and `Game` keep the data and the rules. The form only displays them.
- **File operations:** `FileStream`, `StreamWriter` and `StreamReader` write each result to the txt file and read all results back into the list box.
- **Exception handling:** `try-catch` is used around the dice roll and around saving and reading the file.
- **Pictures:** all pictures are embedded in the program as resources, so there are no file paths and the program works on any computer.
- **Dice roll:** `Random.Next(1, 7)` gives a value from 1 to 6, and the matching dice picture is shown.
